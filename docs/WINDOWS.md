# Windows安装与启动问题

0.1.1安装包的已有验收范围是Windows 11 x64。Windows 10 Home 22H2（19045）曾报告安装器退出、主程序以`0xC000007B`退出；该现场故障尚未定位到具体异常模块。

`0xC000007B`表示Windows加载程序时遇到无效映像格式。仅凭这个退出码不能判断是某个DLL、杀软还是系统策略导致。

重新失败时，请记录：系统版本和位数、程序版本、准确发生时间、退出码；在事件查看器检查同一时间的应用程序错误、CodeIntegrity与安全软件记录。必要时通过系统诊断工具收集DLL加载轨迹，定位具体模块。

`scripts/student-windows-diagnostics.ps1`提供只读取证辅助；先阅读脚本再运行。诊断输出可能包含本机路径或设备信息，请私下提供给维护者并脱敏，不要直接附到公开Issue。

不要关闭杀软或代码完整性策略，不要从不明网站下载DLL，也不要随意替换System32文件。哈希一致只说明拿到同一个文件，不能证明它在本机能够启动。

源码运行可以帮助区分打包与程序问题，但不会自动消除底层Electron或系统加载问题。两条路线的结果需要分别记录。
